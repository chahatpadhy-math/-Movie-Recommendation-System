
# Movie Recommendation System

## Project Description

This project recommends similar movies using
Content-Based Filtering.

It uses movie descriptions, genres and keywords
to find similar movies.

## Dataset

TMDB 5000 Movie Dataset

Kaggle:
https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

## Technologies

- Python
- Pandas
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Streamlit

## Project Features

- Movie selection
- Text preprocessing
- TF-IDF vectorization
- Cosine similarity
- Top 5 movie recommendations
- Streamlit interface

## Installation

Install dependencies:

pip install -r requirements.txt

## Run Application

streamlit run app.py
